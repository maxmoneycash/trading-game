Install on a T-Deck

This replaces the deck's firmware, and the browser can't back yours up first.
This browser can't talk to USB devices. Use Chrome or Edge on a computer. USB needs a secure page (https).
  1. Plug the T-Deck into this computer with a USB-C data cable and switch it on.
  2. Press Connect and install, pick the deck's port (USB JTAG/serial), then Install.
  3. If it won't connect: hold the trackball down, switch the deck on, then try again.

To keep a backup: esptool.py read_flash 0 ALL backup.bin, or tdeck/tools/flash.sh from the repo, which backs up and then flashes.
